# Citing and license

## Citing FNT

If you use FNT in published research, please cite it. The **Cite this repository** button on the [GitHub page](https://github.com/calebvogt/fnt) gives the citation in APA and BibTeX formats, generated from [`CITATION.cff`](https://github.com/calebvogt/fnt/blob/main/CITATION.cff):

```bibtex
@software{fnt,
  title  = {FieldNeuroToolbox (FNT)},
  author = {Vogt, Caleb C. and Garmany, Samuel and Lorman, Sophia G. and Donaldson, Zoe R.},
  url    = {https://github.com/calebvogt/fnt}
}
```

## Attribution in copies and derived work

Under section 7(b) of the license, copies and works based on FNT must keep this attribution, in the source and in any legal notices the work displays (see [`NOTICE`](https://github.com/calebvogt/fnt/blob/main/NOTICE)):

> Based on FieldNeuroToolbox (FNT) by Caleb C. Vogt, Samuel Garmany and contributors, https://github.com/calebvogt/fnt (AGPL-3.0-or-later).

AI coding agents working from a copy of FNT are asked to read [`AGENTS.md`](https://github.com/calebvogt/fnt/blob/main/AGENTS.md), which says how to carry the license and attribution into the new project.
