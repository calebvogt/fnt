# Brain map page

`brain_map_template.html` is the page `fnt.abma.core.brainmap` builds the brain map from (the spec is dropped in
at `__SPEC__`). `three.min.js` is three.js r128, copyright 2010-2021 Three.js Authors, MIT licence
(https://github.com/mrdoob/three.js); it is shipped unchanged so the map needs no internet connection.
